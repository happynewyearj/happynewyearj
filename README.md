# 🎆 Happy New Year 2027

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![GitHub Pages](https://img.shields.io/badge/Demo-Live-brightgreen)](https://happynewyearj.github.io)

A beautiful, interactive New Year celebration web app with fireworks, confetti, and festive animations. Fully responsive for all devices!

## 🌐 Live Demo

**[https://happynewyearj.github.io](https://happynewyearj.github.io)**

## ✨ Features

- 🎆 Realistic fireworks with particle effects
- 🎊 Falling confetti animation
- ⭐ Twinkling starry background
- 🎯 Interactive celebrate button with sound
- 👆 Touch-friendly wish tags
- 📱 Mobile optimized & responsive
- 📳 Haptic feedback support

## 🚀 Quick Start

```bash
# Clone repository
git clone https://github.com/happynewyear2026/happynewyearj.github.io.git

# Open in browser
open index.html
```

Or just visit the [live demo](https://happynewyearj.github.io)!

## 🛠️ Tech Stack

- HTML5
- CSS3 (Animations & Responsive Design)
- Vanilla JavaScript (Canvas API, Web Audio API)

## 📁 Structure

```
├── index.html    # Main application
├── README.md     # Documentation

```

## 🎨 Customization

Change year in `index.html`:
```html
<h1 class="year">2027</h1>
```

Modify colors in CSS:
```css
background: linear-gradient(45deg, #ffd700, #ff6b6b);
```

## 📱 Browser Support

Chrome, Firefox, Safari, Edge, iOS Safari, Android Chrome ✅
